# 战斗规则 v5：逐级提高经验门槛

新建手动战斗和网页 Agent 测试使用 v5。v5 继承 [v4 战斗规则](BATTLE_RULES_V4.md) 的八种敌人、EP、魔力、技能、连战与缺陷靶场；EP 和魔力每级仍分别增加 50 和 5。旧 v1～v4 会话保留各自规则集，恢复和回放时不套用本次升级门槛。

## 升级经验

玩家初始 1 级、经验 0。当前等级为 L 时，升到 L+1 级需要 `15 × L` 经验：1→2 需 15，2→3 需 30，3→4 需 45，之后依次增加 15。

一次击杀得到的经验先加到当前经验；达到当前门槛时升级并扣除该门槛，剩余经验带入下一级。若余量再次达到新门槛，则继续升级。例如 1 级从 0 经验获得 50 经验，会升到 3 级，余 5/45 经验。每次升级照常增加生命上限 20、EP 上限 50、魔力 5 和药水 1，并回满生命及 EP。

网页默认 Agent 伤害动作优先重击；冷却时按陨石、火球、魔法飞弹循环，EP 不足时跳过无法施放的魔法，最后使用普通攻击。开局满血喝一瓶药水用于覆盖药水规则，之后只在生命不超过上限一半时补药。
